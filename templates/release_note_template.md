# Tasket | Tracks — Release note

**8 August 2026**

We're pleased to present **Tasket**. 

For : Tasket End Users

## New: Run one task across parallel workstreams with Tracks

Real work rarely moves in a straight line. A single task often needs spec, design, engineering, QA, and documentation – and until now, one shared status forced all of that into a single line.

**Tracks** changes that. Turn it on for a project and a task can live in several lanes at once, with its own status in each. Now every discipline can see and move its part of the work without waiting on anyone else.

---

You can now run a single task across several workstreams at once – spec, design, engineering, QA, and more – each moving at its own pace.

## What's new

- **Run one task in many lanes.** A task can now sit in several workstreams at the same time, with its own status in each. Finish it in design while it's still in progress in engineering – nothing waits on a single shared status.

- **See everything on the Tracks board.** A new board gives each workstream its own column, so you can watch work move across every stage at a glance.

- **Check a task's full status in one place.** Open any task to see every workstream it's on and where it stands on each.

- **Move a batch forward together.** Select several tasks and push them into the next workstream in one action.

- **Keep working offline.** Start work, mark it done, or reopen it with no network — your changes sync the moment you reconnect.

---

*Tracks is off by default. Any team member can switch it on for a project; only an admin can switch it off.*
